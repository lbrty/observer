Observer может экспортировать данные дел и отчёты в виде CSV-файлов. Для экспорта требуется как минимум роль `consultant` в проекте.

## Экспорт данных дел

Экспорт всех людей и связанных с ними записей для проекта:

```http
GET /projects/:project_id/export/people?format=csv
```

Необязательные параметры запроса:

| Параметр      | Описание                                         |
| ------------- | ------------------------------------------------ |
| `start`       | Фильтр по дате регистрации (ГГГГ-ММ-ДД)          |
| `end`         | Фильтр по дате регистрации (ГГГГ-ММ-ДД)          |
| `category_id` | Фильтр по категории уязвимости                   |
| `tag_id`      | Фильтр по тегу                                   |

Ответ передаётся потоком — большие наборы данных отправляются постепенно, чтобы соединение не прерывалось.

## Экспорт записей поддержки

Экспорт записей консультаций для проекта:

```http
GET /projects/:project_id/export/support-records?format=csv&start=2024-01-01&end=2024-12-31
```

| Параметр  | Описание                                          |
| --------- | ------------------------------------------------- |
| `start`   | Фильтр по дате `provided_at` (ГГГГ-ММ-ДД)        |
| `end`     | Фильтр по дате `provided_at` (ГГГГ-ММ-ДД)        |
| `type`    | `legal` или `social`                              |
| `sphere`  | Сфера поддержки (например, `housing_assistance`)  |

## Экспорт записей о миграции

Экспорт истории передвижений и перемещений:

```http
GET /projects/:project_id/export/migration-records?format=csv
```

## Формат CSV

Все экспорты используют UTF-8 CSV со строкой заголовка. Поля соответствуют той же структуре, что и ответы API. Чувствительные поля (`contact`, `personal`, `documents`) включаются или исключаются в зависимости от флагов разрешений вашего проекта — те же правила, что применяются к чтению через API, применяются и к экспорту.

## Загрузка через веб-интерфейс

1. Откройте проект
2. Нажмите **Экспорт** в навигации
3. Выберите тип записи и диапазон дат
4. Нажмите **Скачать CSV**

Файл загружается непосредственно в ваш браузер.

{{% callout type="note" %}}
Экспорты ограничены вашим проектом. Вы не можете экспортировать данные из проекта, в котором вы не состоите, и ваши флаги чувствительности применяются — если `can_view_personal` отключён, экспортированный CSV не будет содержать национальных идентификаторов или дат рождения.
{{% /callout %}}
