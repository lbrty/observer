Observer може експортувати дані справ і звіти у вигляді CSV-файлів. Для експорту потрібна щонайменше роль `consultant` у проєкті.

## Експорт даних справ

Експорт усіх осіб та пов'язаних із ними записів для проєкту:

```http
GET /projects/:project_id/export/people?format=csv
```

Необов'язкові параметри запиту:

| Параметр      | Опис                                         |
| ------------- | -------------------------------------------- |
| `start`       | Фільтрувати за датою реєстрації (РРРР-ММ-ДД) |
| `end`         | Фільтрувати за датою реєстрації (РРРР-ММ-ДД) |
| `category_id` | Фільтрувати за категорією вразливості        |
| `tag_id`      | Фільтрувати за тегом                         |

Відповідь передається потоком — великі набори даних надсилаються поступово, щоб з'єднання не переривалось.

## Експорт записів підтримки

Експорт записів консультацій для проєкту:

```http
GET /projects/:project_id/export/support-records?format=csv&start=2024-01-01&end=2024-12-31
```

| Параметр | Опис                                            |
| -------- | ----------------------------------------------- |
| `start`  | Фільтрувати за датою `provided_at` (РРРР-ММ-ДД) |
| `end`    | Фільтрувати за датою `provided_at` (РРРР-ММ-ДД) |
| `type`   | `legal` або `social`                            |
| `sphere` | Сфера підтримки (напр. `housing_assistance`)    |

## Експорт записів міграції

Експорт історії переміщень та вимушеного переселення:

```http
GET /projects/:project_id/export/migration-records?format=csv
```

## Формат CSV

Усі експорти використовують UTF-8 CSV із рядком заголовка. Поля відповідають тій самій структурі, що й відповіді API. Чутливі поля (`contact`, `personal`, `documents`) включаються або виключаються залежно від прапорців дозволів вашого проєкту — ті самі правила, що застосовуються до читання через API, застосовуються й до експорту.

## Завантаження через веб-інтерфейс

1. Відкрийте проєкт
2. Натисніть **Експорт** у навігації
3. Виберіть тип запису та діапазон дат
4. Натисніть **Завантажити CSV**

Файл завантажується безпосередньо у ваш браузер.

{{% callout type="note" %}}
Експорти обмежені вашим проєктом. Ви не можете експортувати дані з проєкту, до якого вас не призначено, і ваші прапорці чутливості застосовуються — якщо `can_view_personal` вимкнено, експортований CSV не міститиме національних ідентифікаторів або дат народження.
{{% /callout %}}
